# Chapter-One Bookstore

## Overview

Chapter-One is an online bookstore offering a wide variety of books, including best-sellers, children's books, and new collections. The project consists of a frontend built with HTML, CSS, JavaScript, Bootstrap, and Vue.js, and a backend built with Java (Spring Boot) for handling book inventory, orders, clients, and admin features.

---

## Features

- **Responsive Design**: Built with Bootstrap for a seamless experience across devices.
- **Interactive Carousel**: Display products and categories with an interactive image slider.
- **Product Search and Quick View**: Search for books and quickly view product details.
- **Shopping Cart**: A fully functional shopping cart to manage book purchases.
- **Categories and Collections**: Filter books by categories like "Best Sellers," "New Collection," and "Top Children's Books."
- **Newsletter Subscription**: Visitors can sign up for the newsletter to receive updates on new books.
- **Admin Login**: Admin section for managing the bookstore inventory.

---

## Technologies Used

### Frontend:
- **HTML5**: For the structure of the web pages.
- **CSS3**: For styling and responsive design.
- **JavaScript**: For interactivity and functionality (including Vue.js for reactive components).
- **Bootstrap 5**: For a responsive grid system and pre-built components.
- **Slick Slider**: For creating responsive, customizable carousels.
- **Font Awesome**: For icons used across the website.

### Backend:
- **Java**: The backend logic is implemented using Java with Spring Boot.
- **Spring Boot**: For creating REST APIs, handling the book repository, orders, and clients.
- **JPA (Hibernate)**: For managing database interactions with repositories.
- **H2 Database**: Embedded database for development and testing.
